# Manufacturing Predictive Maintenance | Excel Dashboard

## Project Overview

Designed and developed an **interactive Excel dashboard** to analyze machine performance, failures, maintenance activities, downtime, repair costs and power consumption using a dataset of **2,000 machines**.

## Technologies & Tools

| Technology / Tool         | Purpose                                              |
| ------------------------- | ---------------------------------------------------- |
| Microsoft Excel           | Data cleaning, analysis and dashboard development    |
| PivotTables & PivotCharts | Data summarization and visualization                 |
| Excel Slicers             | Interactive filtering and dynamic reporting          |
| Conditional Formatting    | Data bars, icon sets and visual indicators           |
| Macro Recording           | Refresh, slicer reset, dashboard mode and PDF export |
| Hyperlinks                | Navigation between dashboard sheets                  |
| Git & GitHub              | Version control and project hosting                  |

## Data Preparation & Analysis

- Cleaned unwanted and NULL values and standardized data.
- Created analytical columns for failure risk, maintenance status, recent failures, failure counts and cost categorization.
- Analyzed machine performance, shift-wise failures, planned vs. unplanned maintenance, environmental impact, machine age and downtime.

## Implementation Workflow

1. Imported and explored the manufacturing dataset.
2. Cleaned and prepared data for analysis.
3. Developed PivotTables, PivotCharts and dynamic KPI cards.
4. Connected slicers for interactive dashboard filtering.
5. Recorded macros for refresh, slicer reset, dashboard mode and PDF export.

## Important: Macro Compatibility

The workbook uses **`.xlsm` (Macro-Enabled Excel Workbook)** format. Use Microsoft Excel Desktop for macro functionality. Downloaded files may require Windows security unblocking and trusted macro enablement. Without enabled macros, macro-dependent buttons will not work.
